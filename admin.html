User Data Audit & Repair

Scan and fix user records — deposits vs. ledger mismatches, missing emails, broken profiles, and spin/scratch progress.

Data Migrations

One-time data fixes. Super Admin only. Each of these is safe to run more than once — they only touch records that still need it.

Backfill Lifetime Winnings

Sets lifetimeWinnings for existing users (current Winning Balance + past withdrawals + admin winnings adjustments) so their Profile stat and Earnings Leaderboard show their full history, including money they already withdrew or that was manually corrected — not just what's still in their wallet. Only fills in users who don't already have this field — never overwrites an existing value, and doesn't touch wallet balances at all.

Split Scratch Card Coins from Spin Wheel Coins

Before the coin-tracking fix, Scratch Card coin wins were being added to the same coins field as Spin Wheel — so existing users' Earned Coins totals are a historical mix of both. This re-derives each user's true lifetime Scratch Card earnings from their scratchHistory log, moves that amount into a new scratchCoins field, and subtracts it from coins so Spin Wheel's total becomes accurate too. Safe to run more than once — users already migrated are skipped automatically.
